# Cat vs Dog Image Classification

## About the Project
This is my first beginner-level computer vision and image processing project, created using Python, NumPy, PIL (Pillow), and Google Colab.

The project focuses on loading, displaying, and exploring cat and dog images while practicing fundamental Python and NumPy concepts.

## Project Objectives
- Work with a small dataset of cat and dog images.
- Load and display images using Python.
- Explore image arrays using NumPy.
- Practice basic image processing with PIL.
- Apply Python concepts in a practical project.

## Tools and Technologies
- Python
- NumPy
- PIL (Pillow)
- Google Colab
- Google Drive
